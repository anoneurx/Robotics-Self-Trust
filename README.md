# Robotics-Self-Trust

Research notes on self-trust / self-assessment for robotic perception and control.

## Layout

| Path | Contents |
| --- | --- |
| `comparison-table.html` | Interactive 32-paper comparison matrix; saves to browser `localStorage`, exports CSV |
| `literature/` | `papers.csv` / `papers.json` (one record per paper), per-paper analysis, architecture overlap matrix |
| `papers/` | Citation list in reading order |
| `notes/` | Working notes per topic |
| `experiments/` | `configs/` and `results/` |
| `datasets/` | Dataset inventory and conventions (no raw data in git) |
| `figures/` | Paper figures |
| `references/` | `bibliography.bib` |
